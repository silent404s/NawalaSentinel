1. Cara Kerja Sistem Deteksi Nawala & Internet Positif

Bagaimana sistem mengetahui domain terblokir di 4 operator seluler tanpa harus memiliki kartu SIM fisik?

Prinsip Inti: Nawala dan TrustPositif di Indonesia menerapkan pemblokiran di tingkat jaringan penyedia layanan internet (ISP) melalui DNS Hijacking (Sinkhole) dan HTTP Deep Packet Inspection / Redirection.
A
DNS Sinkhole Query per Operator
Sistem mengirimkan kueri DNS resolusi A-record langsung ke IP server DNS otoritatif milik masing-masing operator seluler:
  • Telkomsel: 180.250.247.1
  • XL Axiata: 202.152.165.2
  • IM3 Indosat: 36.86.63.185
  • Tri (3): 10.19.0.1
Jika domain dialihkan ke IP sinkhole (bukan IP asli server/Cloudflare Anda), sistem seketika menandainya sebagai BLOCKED.
B
Inspeksi HTTP Redirect & Body Signatures
Sistem melakukan koneksi HTTP/HTTPS dan menganalisis apakah terjadi pengalihan (*redirect*) ke portal blokir seperti internetpositif.id, uzone.id, siteblocked.xl.co.id, atau mengandung kata kunci HTML Nawala/Kominfo.
C
Pemeriksaan Berkala Otomatis (Background Scheduler)
Mesin penjadwal berjalan di latar belakang setiap 5 menit sekali secara nonstop (*continuous loop*). Jika terjadi perubahan status pada domain (misal dari normal menjadi terblokir), sistem langsung mencatatnya ke Riwayat Status dan mengirimkan alert darurat ke Telegram.

2. Tutorial Lengkap Setup Bot Telegram

Panduan langkah demi langkah mengintegrasikan Bot Telegram agar Anda dan tim menerima pemberitahuan instan saat domain terblokir atau terkena Suspected Phishing.

1
Buat Bot Baru via @BotFather di Telegram
1. Buka aplikasi Telegram di HP atau Laptop Anda.
2. Cari akun resmi @BotFather (pastikan yang memiliki centang biru terverifikasi).
3. Ketik perintah:
/newbot
4. Masukkan nama tampilan untuk bot Anda, misalnya: Nawala Sentinel Alert.
5. Masukkan username unik yang wajib berakhiran bot, misalnya: tokosaya_alert_bot.
6. BotFather akan memberikan HTTP API Token. Contoh:
7412345678:AAFl8B_abcdef123456789xyz987654321
Salin dan simpan token ini dengan aman.
2
Dapatkan Telegram Chat ID Anda atau ID Grup Tim
A. Jika Notifikasi Dikirim ke Chat Pribadi:
- Buka bot Anda yang baru dibuat, lalu klik Start.
- Cari bot pembantu @getmyid_bot atau @userinfobot di Telegram, lalu ketik /start.
- Salin nomor Your user ID (misal: 123456789).

B. Jika Notifikasi Dikirim ke Grup / Channel Tim:
- Buat grup Telegram baru, lalu undang bot Anda ke dalam grup tersebut.
- Jadikan bot Anda sebagai Administrator grup.
- Undang bot @getmyid_bot ke dalam grup, bot akan menampilkan Current chat ID yang berawalan minus (contoh: -1001987654321).
3
Masukkan Konfigurasi di Halaman Pengaturan
1. Buka menu Pengaturan di panel NawalaSentinel.
2. Masukkan Telegram Bot Token pada kolom yang tersedia.
3. Masukkan Telegram Chat ID (misal: 123456789 atau -1001987654321).
4. Pastikan sakelar Notifikasi Telegram Otomatis dalam posisi aktif (*ON*).
5. Klik tombol Simpan Pengaturan.
4
Uji Coba Pengiriman Notifikasi
Klik tombol Tes Koneksi Telegram di menu Pengaturan. Jika pengaturan Anda sudah benar, bot akan langsung mengirimkan pesan uji coba ke Telegram Anda dalam hitungan detik!
Contoh Notifikasi Alert yang Akan Anda Terima: 
🚨 ALERT: DOMAIN TERBLOKIR NAWALA! 🚨

🌐 Domain: target-jualan.com
📱 Operator: Telkomsel
🔄 Status ISP: NORMAL -> TERBLOKIR (BLOCKED)
🛡️ Status Cloudflare: ⚠️ SUSPECTED PHISHING
🚨 PERHATIAN GANDA: Domain ini terblokir Nawala ISP SEKALIGUS terkena Suspected Phishing di Cloudflare!
🔍 Keterangan: DNS Sinkhole IP terdeteksi (180.250.247.1) via Telkomsel DNS
⏰ Waktu Deteksi: 2026-09-20 01:25:00 WIB

3. Cloudflare Suspected Phishing (Penyebab & Solusi)

Mengapa domain jualan landing page iklan Facebook sering terkena peringatan ini, dan bagaimana menanganinya?

Gejala: Pengunjung yang mengeklik iklan Anda mendapati halaman peringatan merah dengan judul: "Warning - Suspected Phishing: This website has been reported for potential phishing."

Mengapa Ini Terjadi pada Landing Page FB Ads?

  1. Deteksi Otomatis AI Cloudflare terhadap Form Input: Jika landing page memiliki formulir kontak, WhatsApp checkout, atau kolom login yang menyerupai form login portal populer, algoritma anti-abuse Cloudflare dapat salah mengidentifikasinya (*false positive*) sebagai situs phishing.
  2. Lonjakan Trafik Instan pada Domain Baru: Domain baru yang didaftarkan beberapa hari lalu dan langsung menerima ribuan klik dari Facebook Ads akan memicu filter reputasi Cloudflare.
  3. Laporan Kompetitor / Pengguna Facebook: Beberapa pengguna atau kompetitor mungkin sengaja menekan tombol "Report Ad/Site" sehingga memicu interstitial Cloudflare secara otomatis.

Langkah Mengatasi & Menghilangkan Flag Phishing:

1
Ajukan Review Banding (False Positive) ke Cloudflare
Buka halaman pelaporan resmi Cloudflare Trust & Safety:
https://abuse.cloudflare.com/
Pilih opsi "Report a false positive / Phishing Review", jelaskan bahwa domain tersebut adalah website toko online/bisnis resmi Anda, bukan situs pencurian kredensial. Cloudflare biasanya melepas flag dalam 12-24 jam.
2
Gunakan Kolom STATUS CF di Dashboard
NawalaSentinel menyediakan kolom khusus STATUS CF berdampingan dengan STATUS NAWALA. Dengan demikian, jika domain Anda aman di operator seluler tetapi terkena Cloudflare Phishing (atau sebaliknya), Anda bisa mengetahuinya seketika sebelum saldo iklan FB Anda habis terbuang.

4. Format Input Domain & Upload File

Cara memasukkan ribuan link sekaligus dengan cepat dan aman.

A
Paste Ribuan Baris Link (Editor Monospace)
Sistem secara cerdas membersihkan protokol (https://, http://) dan path URL (/login, /promo.html). Anda cukup paste daftar link apa adanya (1 link per baris):
https://toko-jualan.com subdomain.portalresmi.co.id https://landingpage-iklan.com/checkout domain-anda.id
B
Upload File CSV / TXT
Klik tombol Upload CSV / TXT pada panel editor. File Anda akan dibaca secara instan oleh browser dan dimuat ke dalam kotak teks tanpa perlu me-reload halaman.

5. Update Aman via GitHub (aaPanel Zero-Downtime Pipeline)

Bagaimana memperbarui sistem langsung dari GitHub di aaPanel tanpa merusak database dan tanpa mematikan website?

Cara Kerja Tombol Update di Menu Pengaturan:
1. Mengaktifkan Maintenance Lock di memori agar background task pemindaian tidak bentrok saat proses update berlangsung.
2. Menjalankan git fetch & git pull origin main untuk mengambil commit terbaru dari repositori GitHub Anda.
3. Menjalankan init_db() secara otomatis untuk menambahkan kolom baru pada database SQLite tanpa menghapus data domain yang sudah ada.
4. Mengirim sinyal graceful reload ke worker proses server tanpa downtime (pengunjung tetap dapat mengakses website).
Rencana Kedepan (Keamanan Produksi):
Untuk mencegah orang lain menekan tombol pembaruan secara sembarangan di server produksi, sistem telah dirancang untuk menerapkan verifikasi Password Administrator dan 6-digit Google Authenticator OTP (2FA) sebelum perintah update dapat dieksekusi.

6. Pertanyaan Umum & Troubleshooting (FAQ)

Q: Mengapa kolom latency Telkomsel / XL bertuliskan ms (misal 45ms)?

A: Latency (milidetik) menunjukkan seberapa cepat server DNS atau gateway operator seluler tersebut merespons permintaan pengecekan domain Anda. Nilai di bawah 100ms tergolong sangat cepat.

Q: Mengapa waktu di seluruh panel menggunakan WIB?

A: Sistem telah distandarisasi menggunakan zona waktu Asia/Jakarta (WIB, UTC+7). Dengan demikian, waktu terblokir dan catatan log sinkron secara akurat dengan jam operasional bisnis dan iklan Anda di Indonesia, tidak tertinggal 7 jam seperti standar UTC internasional.

Q: Bagaimana jika bot Telegram tidak mengirimkan notifikasi?

A: Pastikan Anda telah mengklik tombol Start pada bot Anda di Telegram. Jika dikirim ke grup, pastikan bot telah dimasukkan ke dalam grup dan Chat ID yang dimasukkan berawalan tanda minus (-). Anda dapat menguji koneksi dengan tombol "Tes Koneksi Telegram" di halaman Pengaturan.
